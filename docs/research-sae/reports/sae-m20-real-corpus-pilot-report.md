# SAE M20 Real-Corpus Efficiency Pilot Report

Date: 2026-05-17

## Scope

This is the first M20 real-corpus efficiency pilot for commons data. It is not a
quality evaluation and intentionally does not report Recall, MRR, NDCG, or MAP.

The goal was to verify whether the read-only evidence-atom payload has a
reasonable physical cost shape on real arxiv/pubmed/policy-like records.

## Important Dimension Finding

The full15 M21 checkpoint uses a 768-dimensional Snowflake teacher:

```text
shared_sae_8192_64
input_dim = 768
```

The current commons vectors on elm are 256-dimensional `rabitq8` vectors:

```text
commons.data_arxiv.vector            -> 256
commons.data_pubmed.vector           -> 256
commons.data_policy_ca_chunks.vector -> 256
```

Therefore the full15 `shared_sae_8192_64` model cannot be applied directly to
commons data. This pilot trains a separate 256-dimensional SAE only to validate
the M20 real-corpus efficiency path.

## Commands

Exported records from elm using stored vectors:

```bash
PYTHONPATH=scripts python3 scripts/research_sae_export_embeddings.py \
  --source postgres \
  --dsn "$DSN" \
  --table commons.data_arxiv \
  --id-column id \
  --text-columns title,abstract \
  --vector-column vector \
  --dequantize-vector \
  --where "vector IS NOT NULL AND (title IS NOT NULL OR abstract IS NOT NULL) ORDER BY publish_date DESC" \
  --limit 5000 \
  --output-dir /Volumes/Betty/Tmp/ii42_sae_real_m20_pilot/arxiv
```

Equivalent exports were run for:

```text
commons.data_pubmed
commons.data_policy_ca_chunks
```

Trained and encoded a 256-dimensional pilot SAE:

```bash
PYTHONPATH=scripts python3 scripts/research_sae_sweep.py \
  --documents /Volumes/Betty/Tmp/ii42_sae_real_m20_pilot/training_combined/documents.jsonl \
  --queries /Volumes/Betty/Tmp/ii42_sae_real_m20_pilot/training_combined/queries.jsonl \
  --output-dir /Volumes/Betty/Tmp/ii42_sae_real_m20_pilot/shared_sae_4096_64_train \
  --latent-dims 4096 \
  --active-dims 64 \
  --score-modes normalized_idf_dot \
  --epochs 8 \
  --batch-size 256 \
  --device mps \
  --top-k 100
```

## Decision

The M20 pilot passes as an efficiency-path sanity check:

```text
EATMH002/head16_doc128 remains the preferred read-only payload shape.
```

It cuts mean rerank terms from `210,656.7400` to `136,740.0833` and C reader
latency from `0.3577 ms` to `0.2503 ms` on the 5k real-corpus pilot.

The pilot also exposes a later model-lineage choice:

```text
commons production path needs a 256-dimensional SAE lineage,
or commons must regenerate/store 768-dimensional embeddings.
```

Until that decision is made, the 768-dimensional BEIR/full15 model and the
256-dimensional commons pilot should be treated as separate evidence lines.
