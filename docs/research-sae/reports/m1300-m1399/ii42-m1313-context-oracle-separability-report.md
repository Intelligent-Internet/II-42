# M1313 Context Oracle Separability Report

## Question

M1311 failed as a two-stage selector, and M1312 failed as a global atom-prior
source. M1313 asks whether richer query-local context makes the missing signal
observable before any replay:

- movement-source summaries from M1311;
- action-local top8 delta statistics from `high`, `mid`, and `low`;
- native document-support features over top/boundary/tail candidate windows;
- CUB-specific contrast features from the training fold.

The target labels are query-level:

- `oracle_move`: M1309 all-safe oracle chooses a movement source;
- `safe_gain`: fixed `signed_sum_s1` is all-safe with positive utility;
- `rank_harm`: fixed `signed_sum_s1` has at least one negative metric.

This is a separability audit only. It does not replay a new native source.

## Interpretation

M1313 is another stop signal for selector-style routing on the current source.

The action features are the best of the tested groups, but still only reach
about `0.60` AUC for `oracle_move` / `safe_gain` and about `0.53` for
`rank_harm`. Native document support does not recover the missing signal, and
combining all features actually weakens AUC, suggesting dataset shift/noise
rather than an underfit linear model.

This result is consistent with prior evidence:

- M1245: action-source routing has a strong oracle but weak query-time
  observability;
- M1253: fixed `signed_sum_s1` harm is not separable from simple buckets;
- M1311: two-stage move/source selection over movement summaries fails;
- M1312: global atom move/abstain priors are too coarse.

## Decision

Do not replay this M1313 context feature family.

Do not train a deeper model over the same movement/action/support feature set.

The next useful route must change the teacher/source construction itself. In
particular, the source should not be a fixed signed-sum set plus selector; it
needs to be generated by an objective that internalizes rank preservation and
false-move abstention at construction time.

Minimum gate for the next branch:

1. show target/harm separability above the current ceiling (`AUC >= 0.65`) on
   hard-row smoke before native replay;
2. avoid global atom priors and ordinary query gates;
3. produce query-local posting deltas, not an external reranker;
4. scale only after the smoke beats fixed `signed_sum_s1` without MRR/NDCG
   harm.
